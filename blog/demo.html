Introduction

Every so often a problem in the history of science turns out to hinge on a single stubborn geometric relationship. Kepler's struggle with Mars is exactly that kind of problem — eight minutes of arc that refused to fit any circular model, no matter how many epicycles were piled on.

"I have shaken the astronomical theories of Antiquity down to the last stone." — the frustration is understandable once you see the geometry involved.

The Geometry Problem

The vicarious hypothesis treats the equant point as unknown, solving for its position using observed oppositions rather than assuming it bisects the eccentricity. This single change is what let Kepler match Tycho's data far more precisely than any Ptolemaic or Copernican model before him — and it's the direct ancestor of what became the area law.

  • Four oppositions provide four independent triangles
  • Each triangle constrains the equant location differently
  • Consistency across all four is the real test of the model

Sample Calculation

Here's a minimal snippet for solving the equant offset numerically:

function solveEquant(oppositions) {
  // Newton-Raphson iteration on the four-triangle
  // consistency condition described above.
  let e = 0.1; // initial eccentricity guess
  for (let i = 0; i < 50; i++) {
    const residual = triangleResidual(oppositions, e);
    const derivative = numericalDerivative(oppositions, e);
    e -= residual / derivative;
  }
  return e;
}
